Motor de transcripción

Si elegís Groq o Deepgram y se corta el internet, la app pasa sola al modo local y vuelve cuando regresa la conexión.

Cómo conseguirla (gratis, sin tarjeta): entrá a console.groq.com, creá una cuenta y, en "API Keys", tocá "Create API Key". Pegala acá. Groq transcribe cada frase cuando termina de decirse, así que el texto aparece un instante después que con Deepgram. Tiene un límite diario gratuito; si se agota, la app sigue sola en modo local. La clave queda guardada solo en este dispositivo.

Cómo conseguirla (sin tarjeta, trae US$200 de crédito que no vence): entrá a console.deepgram.com, creá una cuenta y, en "API Keys", tocá "Create a New API Key". Pegala acá. Con el crédito inicial alcanzan cientos de horas; después cuesta alrededor de 40 a 60 centavos de dólar por hora de conversación. La clave queda guardada solo en este dispositivo.
